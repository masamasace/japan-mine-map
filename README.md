# 日本の鉱山マップ

産総研 地質調査総合センターの「国内の鉱床・鉱徴地に関する位置データ集（第2版）」に収録された鉱山・鉱床の位置を、国土地理院の地理院タイルを背景にして表示する地図です。背景には、過去と現在の航空写真、陰影起伏図、標高（色別標高図）を使えます。開いたときの背景は 1974〜1978 年の航空写真です。

- 地図: https://masamasace.github.io/japan-mine-map/
- 点は 12,981 件あり、開いたときは採掘歴のある 10,891 件を表示します。採掘歴を判断できない点と採掘歴のない点は、「鉱山の絞り込み」から表示できます。
- 位置は地質図幅に描かれた鉱床記号の中心で、記号の大きさ（紙面で約 2 mm）より細かい精度はありません。20 万分の 1 図幅では地上で約 400 m、5 万分の 1 では約 100 m に当たります。
- 同じ鉱山が複数の図幅に載っていると、点も複数になります。鉱種と凡例は図幅の記載のままで、図幅の出版後の稼行状況は反映していません。

- USGS の Mineral Resources Data System（MRDS）で国名が Japan の 415 件を、紫の四角の別の層として重ねています。四角の大きさは MRDS の生産規模（大・中・小）、二重枠は「世界的に重要な鉱床」の印です。大・中・小の基準は MRDS に記録されていません。産総研の点とは統合せず、ポップアップに 2 km 以内の産総研の点を示します。開いたときは製錬所などの工場を除いた 291 件を表示します。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 地図のページ（Leaflet 1.9.4） |
| `mines.json` | 鉱山の位置データ。出典の CSV（cp932）を UTF-8 の表に変えたもの |
| `mrds.json` | MRDS の日本の 415 件。名称・開発状況・鉱種・生産規模・鉱床規模・世界的に重要か・総資源量・生産開始年・位置と、2 km 以内の産総研の点の行番号と距離 |

`mines.json` の `rows` の各行は、`fields` の順に `id, name, mineral_j, legend, cat, mineral_id, work, map, lat, lon` です。`map` は `maps` の行番号（図幅名、出版年、出版者、URI）です。値は出典のままです。ただし id 10816 の区分 ID は、出典の 23 を 2（非金属鉱物）に直しています。この行の鉱種 ID 202 が、報告書で非金属鉱物に分類されているためです。

## 出典と利用条件

- 鉱山の位置: 内藤一樹（2017）国内の鉱床・鉱徴地に関する位置データ集（第2版）. 地質調査総合センター速報 no.73. 産業技術総合研究所 地質調査総合センター（データ 2025年12月15日更新）. https://www.gsj.jp/publications/pub/prompt-rep/index.html
  - [政府標準利用規約（第2.0版）](https://www.gsj.jp/license/index.html)に従い、形式を変えて掲載しています。
- MRDS: U.S. Geological Survey, Mineral Resources Data System（rdbms-tab-all.zip、2019年3月6日の抽出）. https://mrdata.usgs.gov/mrds/ 。メタデータの利用制限は none です。
- 背景: 国土地理院 [地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)（空中写真 1945〜1990 年、全国最新写真（シームレス）、陰影起伏図、色別標高図、淡色地図、標準地図）。タイルはページから直接読み込んでいます。
